# Contributor instructions

## Language

- Use English for all repository documentation, source code, identifiers, comments, docstrings, test names, fixtures, and developer-facing messages.
- Use English for new branch names, commit messages, and pull request titles and descriptions.
- Keep domain terminology in English regardless of the user interface language.
- Localized user-facing content may use its target language only in explicitly identified localization resources or localization test cases.
- Communicate with the repository owner in their preferred language; this does not change the repository's English convention.

## Product planning

- Treat `docs/product/pilot-prd.md` as the pilot scope reference.
- Keep proposed decisions distinct from agreed decisions.
- Track technical stages and validation in `docs/engineering/pilot-plan.md` once it exists, linking to PRs.
- Do not copy personal athlete data, photos, or logs into this repository.
